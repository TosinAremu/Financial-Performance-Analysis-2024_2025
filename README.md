# Financial-Performance-Analysis-2024_2025
## A Comprehensive Financial Performance Review (2024-2025)
### Tools: Microsoft Power BI | Power Query | DAX | Data Modelling | Fianancial Analysis

## Project Overview
This project presents an interactive Power BI financial performance analysis of a Nigerian buiness, employing 4,500 financial transactions recorded between 2024 and 2025, broadly speaking.

The analysis evaluates revenue growth, cost of sales, operating expenses, profitability, departmental spending and branch level performance.

The primary aim is to understand why important revenue growth didn't translate into the raised profitability and spot opportunities for stronger financial management, in real-world scenarios.

Financial reporting, data modelling, DAX calculations and interactive visualisations are being combined by the project to support indication based management decisions, to a significant degree.

## Business Objectives

The analysis was developed to address six key objectives:
1. Build an interactive monthly Profit and Loss statement.
2. Compare financial performance between 2024 and 2025.
3. Analyse revenue, cost of sales and operating expenses trend.
4. Identify the principal drivers of declining profitability.
5. Evaluate branch profitability and departmental cost efficiency.
6. Develop three strategicmanagemnt recommendations based on the findings.

## Dataset Overview

The dataset contains 4,500 financial transactions covering the 2024-2025 reporting period across eight branches and ten departments.

The financial records include:
- Transation dates and reference numbers
- Account classifications and transaction types
- Revenue and expenditure amounts in Nigeria (NGN)
- Branch and departmental allocations
- Cost centre classifications
- Payment methods and transactions status

The dataset supports financial reporting, profitability analysis, expenses monitoring and year on year performance comparisons.
